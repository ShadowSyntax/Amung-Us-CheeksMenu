CheeksMenu
A feature-rich Among Us cheat menu built with BepInEx.

Requirements

Among Us (PC via Steam)
BepInEx 6 (IL2CPP build)


Installation
Step 1 — Install BepInEx

Download BepInEx 6 IL2CPP from the BepInEx releases page: https://github.com/BepInEx/BepInEx

You want the file named something like BepInEx_il2cpp_win_x64_6.x.x.zip


Extract the zip into your Among Us game folder

Default location: C:\Program Files (x86)\Steam\steamapps\common\Among Us\
After extracting you should see a BepInEx folder and winhttp.dll sitting next to Among Us.exe


Run the game once and close it — BepInEx will generate its folder structure including the plugins folder

Step 2 — Install CheeksMenu

Download the latest release 

Copy CheeksMenu.dll into:

   Among Us\BepInEx\plugins\

Launch the game — the menu will load automatically


Usage

ActionKeyOpen / Close Menu "DEL"

Navigate tabs Click the tab names on the leftToggle

Scroll wheel in tabs for all options


Notes

Host-Only features require you to be the lobby host to function correctly
Role assignment (Set Self/Other Role) applies at the start of the next game, not immediately in lobby
Hotkey bindings are saved and persist between sessions
The minimap and player picker windows are draggable — position them wherever you like
