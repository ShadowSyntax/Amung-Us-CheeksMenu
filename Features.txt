# CheeksMenu Features

## 🎮 Player
| Feature | Description |
|---|---|
| NoClip | Walk through walls |
| SpeedHack | 2x movement speed |
| **Teleport** → to Cursor | Right-click to teleport to cursor position |
| **Teleport** → to Player | Teleport to a selected player |

| Feature | Description |
|---|---|
| See Roles | See every player's role above their head |
| See Ghosts | See dead players/ghosts |
| No Shadows | Full brightness, no fog of war |
| Reveal Votes | See who voted for who during meetings |
| **Camera** → Zoom Out | Zoomed out camera view |
| **Camera** → Spectate | Follow another player's perspective |
| **Camera** → Freecam | Free-moving camera anywhere on the map |
| **Tracers** → Crewmates | Lines pointing to all crewmates |
| **Tracers** → Impostors | Lines pointing to all impostors |
| **Tracers** → Ghosts | Lines pointing to dead players |
| **Tracers** → Dead Bodies | Lines pointing to unreported bodies |
| **Tracers** → Color-based | Tracers colored by player color |
| **Minimap** → Show Minimap | Live minimap overlay |
| **Minimap** → Crewmates | Show crewmates on minimap |
| **Minimap** → Impostors | Show impostors on minimap |
| **Minimap** → Ghosts | Show ghosts on minimap |
| **Minimap** → Color-based | Minimap dots colored by player color |
